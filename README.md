# Китбуль — дружба начинается с маленького «привет»

Адаптивный сайт в стиле рисованного альбома: бумажная фактура, коралловые акценты, фоторамки, рукописные подписи. Без градиентов.

## Как открыть

Откройте `index.html` двойным кликом. В архиве для скачивания файлы сайта находятся в папке `kitbull-site`: просто откройте в ней `index.html`.

Сборка и установка зависимостей не нужны. Все изображения и шрифты включены. Основные разделы, галерея, игра и кнопка со следами работают без интернета. Для просмотра фильма предусмотрены ссылки на Disney+ и страницу Pixar. Для внешних сервисов нужен интернет; доступность фильма зависит от региона и подписки.

## Что внутри

- Главный экран, история фильма и знакомство с двумя героями.
- Игра с клубком: три шага, которые сближают котёнка и пса. Это авторская интерактивная иллюстрация темы доверия.
- Галерея с увеличением кадров и афиши.
- Окно с официальными ссылками для просмотра фильма.
- Интерактивная тропинка из тёплых следов.
- Мобильное меню, доступные диалоговые окна, поддержка уменьшенного движения.

## Файлы

`index.html` — структура и тексты. `style.css` — оформление. `app.js` — интерактивные элементы. `fonts.css` и `assets/` — локальные материалы.

Технологии: HTML, CSS, JavaScript. Внешних библиотек нет.
